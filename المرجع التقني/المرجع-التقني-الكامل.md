## أنواع التسعير الثمانية

| النوع | المعرّف | الصيغة |
|-------|---------|--------|
| سعر ثابت | `fixed` | `price = product.price` |
| متر مربع | `sqm` | `max(150, round(w/100 * h/100 * price))` |
| جوز حسب العرض | `pair_width` | `round(w * price / 100 * 2)` |
| قطعة حسب العرض | `single_width` | `round(w * price / 100)` |
| نمر جوز ثابت | `plate_pair` | `price = product.price` |
| نمرة مفردة ثابتة | `plate_single` | `price = product.price` |
| خيارات بالكمية | `plate_qty` | `preset_sizes[qty - 1]` |
| سعر مختلف لكل حجم | `fixed_per_size` | `size_prices[preset_sizes.indexOf(w)]` |

### plate_qty — تفاصيل

- `preset_sizes` = الأسعار مثل `[150, 250, 350]`
- `qty_labels` = الأسماء مثل `["مكعب واحد","مكعبين","3 مكعبات"]` (اختياري)
- عدد الأزرار = طول `preset_sizes` (ديناميكي)

### shape — معاينة الحجم

| القيمة | السلوك |
|--------|--------|
| `'rectangle'` | حقلا عرض + ارتفاع، معاينة مستطيلة |
| `'circle'` | حقل قطر واحد، معاينة دائرية، `⌀` في الوصف |

### compare_prices — حملات الخصم

- لـ `fixed/plate_pair/plate_single`: يُعرض `compare_prices[0]` مشطوباً + % الخصم
- لـ `fixed_per_size`: يُعرض `compare_prices[i]` بجانب كل حجم
- لـ `plate_qty`: غير مدعوم

## نظام اللغات (i18n) — 3 لغات

### كيف يعمل

1. **عند الدخول الأول**: يكشف لغة المتصفح تلقائياً (`navigator.language`)
2. **عند تغيير اليد**: يحفظ الاختيار في `localStorage` تحت مفتاح `luxsign_locale`
3. **الفول باك**: العربي دائماً إذا لم تُوجد ترجمة

### كشف اللغة التلقائي

```js
// LocaleContext.jsx
function detectLocale() {
    const saved = localStorage.getItem('luxsign_locale');
    if (['ar', 'he', 'en'].includes(saved)) return saved;
    const lang = (navigator.language || '').slice(0, 2).toLowerCase();
    if (lang === 'he') return 'he';
    if (lang === 'en') return 'en';
    return 'ar';  // الافتراضي
}
```

### اللغات المدعومة

| الكود | اللغة | الخط | الكشف التلقائي |
|-------|-------|------|----------------|
| `ar` | العربية | Cairo | كل لغة غير he/en |
| `he` | العبرية | Heebo | `navigator.language` يبدأ بـ 'he' |
| `en` | الإنجليزية | Heebo | `navigator.language` يبدأ بـ 'en' |

### ملف الترجمات: `resources/js/i18n.js`

```js
export const translations = { ar, he, en };

// دالة الحصول على الحقل المترجم من قاعدة البيانات
export function localField(obj, field, locale) {
    if (!obj) return '';
    if (locale === 'ar') return obj[field] ?? '';
    const val = obj[`${field}_${locale}`];   // مثل: product.name_he
    return (val && val.trim()) ? val : (obj[field] ?? '');  // fallback للعربي
}
```

### `localField` — كيف يُستخدم في الـ Frontend

#### 2. SecurityHeaders — رؤوس الأمان (CSP)

```php

X-Frame-Options: SAMEORIGIN

Referrer-Policy: strict-origin-when-cross-origin
// يحذف: X-Powered-By, Server
```

#### مسار التسجيل (bootstrap/app.php)


### ⚠️ تحذيرات مهمة لأي جلسة قادمة

**لا تستخدم PowerShell `Get-Content`/`Set-Content` لتعديل أي ملف فيه نص عربي/عبري أو إيموجي.** بدون `-Encoding UTF8` صريحة على القراءة، PowerShell 5.1 بيقرأ بترميز خاطئ ويحوّل كل حرف متعدد البايت (إيموجي، ₪، عربي/عبري) لرموز مشوّهة (mojibake) بشكل دائم بمجرد ما تنكتب النسخة "المصلَّحة". استخدم أداة Edit/Write حصراً لأي تعديل نصي بهالمشروع.

**ملف `public/hot`** إذا ظل موجود (من جلسة `npm run dev` سابقة) بيخلي Laravel يحمّل أصول Vite من `http://127.0.0.1:5173` (localhost) بدل نسخة الإنتاج — هذا يسبب شاشة بيضاء تماماً لما تفتح الموقع من جهاز تاني (موبايل) عبر IP الشبكة. لازم تتأكد إنه محذوف قبل استخدام `php artisan serve` للاختبار من الموبايل.
